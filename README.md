# Sistema de IA
Proyecto de practica para la materia Arquitectura de Sistemas de Inteligencia Artificial.

## Descripción
Este proyecto simula la estructura base de un sistema de Inteligencia Artificial para practicar el control de versiones.

## Objetivo
Administrar las versiones de un proyecto y comprender el flujo colaborativo.

## Componentes
- Modelo
- Inferencia
- Configuracion
- Documentacion
